# Lantern Cat Café trailer (2:00)

Everything needed to rebuild the trailer from the real game, with original music, and to drop in the
owner's voiceover without re-editing.

| File | What it is |
|---|---|
| `timeline.py` | **Single source of truth.** 96 BPM grid (bar = 2.5 s), 42 shots, 14 VO lines, SFX hits, on-screen text. |
| `VO-SCRIPT.md` | Recording script for the owner (generated by `gen_script.py` from the timeline). |
| `CHAIN-FACTS.md` | The real Fuji transactions behind every economy number on screen. |
| `compose_score.py` | Original score, written note by note, rendered with FluidSynth + MuseScore_General (MIT). |
| `build_sfx.py` | Designed hits (synthesised) + CC0 / in-game SFX placed on picture events. |
| `temp_vo.py` | Placeholder narration (Kokoro-82M, Apache-2.0) for timing review only. |
| `place_vo.py` | Places recorded lines (per-line files or one take) on their cues; checks slot lengths. |
| `mix.py` | Stems → ducking under VO → silence gate on the stop-down → −14 LUFS / −1 dBTP master. |
| `capture_shot.mjs` + `final*.json` | Frame-exact 1080p30 recorder for game footage (virtual time, any renderer speed); `finalA`–`finalG` are the specs behind the final cut (`shots.json` = older captures). |
| `titles/` + `render_titles.mjs` | Animated title / name / boss / proof cards in the game's fonts (alpha .mov). |
| `cut.json` + `assemble.py` | Maps each timeline shot to footage (in-point, Ken Burns, grade, slow-mo) and cuts the picture. |

## Structure (why 2:00, not 3:00)

Research (Derek Lieu's hook/genre/content structure, GMTK, Steam guidance) says hook in the first
5–10 s, show gameplay early, and keep a store trailer to 60–90 s. This trailer must also explain an
on-chain economy to judges, so it runs 2:00 and leaves the 3-minute live demo to carry depth.
Combat is never a long take: it appears in 1.25–2.5 s cuts, about 40 s in total across the hook,
core loop and boss climax, with the rest given to world, route choices, progression, economy and
the call to action.

| Time | Section | Content |
|---|---|---|
| 0:00 | Cold open | Night café, the Tangle, Soot's Chimney Comet on the first hit, a beat of silence, title. |
| 0:07.5 | Premise | Café home, Mochi / Clover / Soot name cards, 12 cats. |
| 0:20 | Core loop | Route map, events, battle, tapping an ultimate, victory. |
| 0:40 | Progression | Gear drops, equip, Forge, three chapters. |
| 0:55 | Ownership | "Earned by playing, never bought", then real Fuji proof: seal burn, market sale fee burn, supply counter. |
| 1:15 | Climax | Three bosses, half-bar montage, riser, one bar of silence + whisper, final blow in slow motion. |
| 1:45 | Resolve | Warm café, lockup, "Play free in your browser", testnet disclaimer. |

## Rebuild

```sh
# 0) game preview on :6301 (from repo root)
node tools/v5int/run-chain-mode.mjs --fixture
# 1) footage (repo root)
TRAILER_REPO=$PWD node trailer/capture_shot.mjs trailer/finalA.json   # then finalB..finalG
# 2) audio + titles (in trailer/)
python3 timeline.py && python3 compose_score.py && python3 build_sfx.py
/home/user/kvenv/bin/python temp_vo.py && python3 place_vo.py vo/temp audio/vo_temp.wav
python3 mix.py && python3 mix.py --vo audio/vo_temp.wav
node render_titles.mjs
# 3) picture + deliverables
python3 assemble.py --audio audio/mix_novo.wav --out out/trailer_review_noVO.mp4
python3 assemble.py --reuse --audio audio/mix_vo.wav --out out/trailer_tempVO.mp4
```

Tools: ffmpeg, Python 3 with numpy/scipy/pretty_midi, `fluidsynth` + `MuseScore_General.sf2`
(set `SF2=`), Playwright Chromium from `apps/web`. Kokoro needs a Python 3.12 venv.
